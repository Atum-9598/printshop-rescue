Questions

Is the preview really free?

Yes. It runs inside your web browser. Your file is never sent anywhere.

Why can't I open these files anymore?

The programs that made them stopped working on modern Windows and Mac, and newer Print Shop versions can't read the oldest files.

Do I need to install anything?

No. Just this page for the preview, and email for the full-quality PDFs.
